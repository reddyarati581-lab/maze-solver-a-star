# PROJECT REPORT
## Maze Solver Using A* Search Algorithm

### 1. Introduction
Maze Solver is a Python-based Artificial Intelligence project. It finds the shortest path from a starting point to a goal in a maze using the A* Search algorithm.

### 2. Objectives
- To develop a maze-solving application using Python.
- To implement the A* Search algorithm.
- To find the shortest path.
- To identify blocked and unreachable paths.

### 3. Technologies Used
- Python Programming
- Artificial Intelligence
- A* Search Algorithm
- Manhattan Distance

### 4. Methodology
The maze is represented using a 2D grid. The value 0 represents an empty cell, and 1 represents a wall. The A* algorithm explores possible paths and selects the path with the lowest estimated cost.

### 5. Algorithm
1. Create a 2D maze.
2. Define the start and goal positions.
3. Calculate Manhattan distance.
4. Explore available neighboring cells.
5. Calculate the total path cost.
6. Find the shortest path.
7. Display the final maze.

### 6. Advantages
- Finds the shortest path.
- Avoids blocked cells.
- Uses an efficient search technique.
- Demonstrates Artificial Intelligence concepts.

### 7. Conclusion
This project demonstrates the working of the A* Search algorithm using Python. It helps find the shortest path between two points in a maze.
