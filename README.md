# Maze Solver Using A* Search

## Project Description
This project is a Maze Solver developed using Python and Artificial Intelligence. It uses the A* Search algorithm to find the shortest path from the starting point to the goal.

## Objectives
- Represent a maze using a 2D grid.
- Implement the A* Search algorithm.
- Find the shortest path.
- Handle blocked and unreachable paths.

## Technologies Used
- Python
- Artificial Intelligence
- A* Search Algorithm
- Manhattan Distance

## Algorithm
1. Create a maze using a 2D grid.
2. Define the start and goal positions.
3. Calculate Manhattan distance.
4. Explore possible paths using A* Search.
5. Find the shortest path to the goal.
6. Display the final maze with the path.

## How to Run
1. Install Python.
2. Open the terminal.
3. Run the command:

python maze_solver.py

## Output Symbols
- S = Start
- G = Goal
- # = Wall
- * = Shortest Path
- . = Empty Cell

## Conclusion
This project demonstrates how the A* Search algorithm can efficiently find the shortest path in a maze.
